BrightPath Employee Dashboard

A centralized Google Workspace administration and IT security platform built for BrightPath LLC. Manage group memberships, audit security, monitor threats, track admin changes, sync JazzHR candidates, and manage employee email accounts — all from one URL.

Google Group
Membership management for all 9 BrightPath Google Groups

View every active GWS user alongside their current group memberships. Select users, choose which groups to add or remove them from, and apply the change instantly — no Google Admin Console needed.

1
Browse users — all 230+ GWS accounts listed with Doc Status, Date of Hire, Position, and current groups. Sorted newest-first by default.
2
Check a row — Groups column expands into toggles for all 9 groups. Check the ones you want to add or remove.
3
Click Add or Remove — confirm in the modal and the change is applied live to Google Admin.
4
Filter & search — by Status, Role, Group, Position, Date of Hire range, or free-text search.
*admin_team*all_staff*corporate*directors*residential*supervisors*ubsgcp-billing-adminsgcp-organization-admins
Group Audit
Security review — find and remove terminated users from groups

Pulls every group membership across all Google Groups in the domain and checks each member's current GWS account status. Surfaces terminated employees still in active groups — a common offboarding gap.

1
Click Refresh Data — reads all groups, lists every member, checks each account status. Takes 1–3 minutes.
2
Review KPI cards — see how many members are Active, Suspended, Terminated, or Error at a glance.
3
Filter by Terminated — removal panel appears. Select users and click Remove from Groups.
4
Export CSV — download the full or filtered membership list for compliance records.
ACTIVESUSPENDEDTERMINATEDERROR
JazzHR
Direct API pull — applicants and prospects deduplicated

Connects directly to the JazzHR API and pulls all applicants and prospects into a single deduplicated table. Cross-reference candidates by Centrally HR ID, JazzHR ID, or email address.

1
Click Fetch from JazzHR — pulls all pages of applicants and prospects, deduplicates by JazzHR ID.
2
Data is cached — loads instantly on subsequent opens. Auto-refreshes every 6 hours.
3
Search — find by name, email, JazzHR ID, or Centrally HR ID to verify a candidate exists.
Centrally HR IDJazzHR IDDeduplication6hr auto-sync
Email Creation
New hire onboarding — create, suspend, and reactivate GWS accounts

Reads from the New Hire Onboarding Tracker, auto-generates each employee's BrightPath email from their name, and checks live GWS account status. Create, suspend, or reactivate accounts in bulk with a confirmation step before every action.

1
Email auto-generated — format is firstname.lastname@brightpath-mn.com from the Name column.
2
Live status check — Email Status is checked against Google Admin on every refresh: NO EMAIL, ACTIVE, SUSPENDED, TERMINATED, ERROR.
3
Select → Action — Create Email creates account with temp password. Suspend disables. Reactivate re-enables.
4
Smart skipping — each action only processes eligible records and shows per-user outcome in a results modal.
Create EmailSuspend UserReactivateTemp Password
2FA
2FA enrollment across all 230+ active BrightPath accounts

Pulls live from Google Admin using the isEnrolledIn2Sv field to show exactly which active accounts have 2-Factor Authentication enabled or not. Excludes Workspace Guests.

1
4 KPI cards — Total Active Accounts, 2FA Enabled (green), No 2FA (red), Coverage %.
2
Progress bar — Green ≥80%, Amber ≥50%, Red <50% enrollment. Instant visual of security posture.
3
Filter by 2FA Status — quickly isolate all users without 2FA to prioritize follow-up.
4
Export CSV — download the full list with 2FA status for compliance reporting or management review.
2FA EnabledNo 2FALive from Google Admin
Email Threats
Suspicious logins, failed auth & risky OAuth app grants — last 7 days

Pulls from the Google Workspace Reports API (Login + Token audits) to surface suspicious login events, failed authentication attempts, and risky third-party OAuth app authorizations across the domain.

1
Login Audit — catches suspicious_login, suspicious_programmatic_login, login_failure, and login_challenge events. Rated HIGH/MEDIUM/LOW by type.
2
Token Audit — shows OAuth app authorizations and revocations. Helps identify if a user granted access to a suspicious third-party app.
3
Filter by Severity — HIGH (suspicious logins), MEDIUM, LOW (failures), INFO (token events).
HIGHMEDIUMLOWINFO7-day window
Login Monitor
Full login activity log with IP address, country & device — last 7 days

Pulls the complete login audit trail from the Google Reports API — every login event for every user in the past 7 days, with IP address, country, and device type. Essential for spotting account takeover attempts or travel anomalies.

1
Full login trail — every login_success, login_failure, login_challenge, and suspicious_login event for all users.
2
Filter by Event Type — quickly isolate Failed Logins or Suspicious Logins to prioritize investigation.
3
Search by user or IP — look up a specific employee's login history or trace an unfamiliar IP address.
4
Export CSV — full login report for incident response or compliance documentation.

Admin Activity
Every Google Admin console change — last 7 days

Pulls the Admin audit trail from Google Reports API — a complete log of every change made in the Google Admin Console: user creation, deletion, suspension, group changes, permission grants, and settings modifications.

1
Full audit trail — who changed what, when. Every admin action logged with the acting admin's email, action taken, and affected user or target.
2
Filter by Category — USER_SETTINGS, GROUP_SETTINGS, ADMIN_SETTINGS, PASSWORD_SETTINGS, DOMAIN_SETTINGS.
3
Search — find all actions taken by a specific admin, or all changes affecting a specific user.
4
Export CSV — full admin change log for audit trails, SOC reviews, or compliance documentation.

Drive Exposure
Files shared publicly or outside brightpath-mn.com — last 7 days

Pulls Drive sharing events from the Google Reports API to identify files that have been shared publicly (anyone with link), externally (outside brightpath-mn.com), or domain-wide. Helps prevent accidental data exposure.

1
Three exposure types — PUBLIC (anyone on the internet), EXTERNAL (specific outside user), DOMAIN (all BrightPath staff). Sorted by risk level.
2
Filter by type — focus on the highest risk first. Public sharing is the most critical and appears at the top.
3
Search by file or owner — trace who shared a specific file or see all files shared by a particular employee.
4
Export CSV — full exposure report for data governance, compliance, or incident response.
PUBLICEXTERNALDOMAIN7-day window
Password Security
HIPAA 180-day compliance — view, filter, and remediate password risk across all active accounts

Pulls lastPasswordChangeTime from Google Admin for every active account and calculates password age against BrightPath's HIPAA 180-day policy. Risk-ranked with 5 KPI cards combining 2FA status and password age. Includes a Force Password Reset action for CRITICAL and HIGH risk accounts.

1
5 Risk KPI cards — Critical (no 2FA + bad password), High (overdue/never changed), Medium (no 2FA or due soon), OK (2FA + current). Click any card to filter the table.
2
6 stat chips — Overdue, Due Soon, Never Changed, Unknown, No 2FA, and Change Required counts at a glance.
3
13-column sortable table — checkbox (Critical/High only), Risk Level, Password Status, 2FA, Account Created, Last Changed, Days Since, Days Until Due, Org Unit, and Change @ Login.
4
Force Password Reset — select one or more CRITICAL or HIGH risk users, then click Force Password Reset. A confirmation modal shows who will be affected before any action is taken. Selected users are forced to set a new password at next sign-in.
5
Export CSV — full password age + risk report for HIPAA compliance documentation, management review, or audit evidence. Respects active filters.
CRITICAL HIGH MEDIUM OK Force Reset HIPAA 180-day

Access & Security: This dashboard is restricted to authorized BrightPath admins only (michael.sevilla@, jeremy.garrigan@, brandon.spears@brightpath-mn.com). All actions execute under a Super Admin Google Workspace account and are logged in the Apps Script execution log. The dashboard runs entirely within your BrightPath Google Workspace domain — no data leaves the organization. Security tabs (Email Threats, Login Monitor, Admin Activity, Drive Exposure, Password Security) pull read-only data from Google APIs. The only write actions available are: adding/removing group memberships, creating/suspending/reactivating email accounts, and forcing password resets on CRITICAL or HIGH risk accounts — all require explicit confirmation before executing.
